Chapter 2

RAG evaluation

  • Faithfulness — answer supported by retrieved chunks (RAGAS)
  • Citation hit rate — cited chunk IDs match gold doc IDs
  • Golden set — question + expected doc IDs + answer snippet

Component eval: measure retrieval Recall@k before end-to-end faithfulness.

Chapter 3

Agent evaluation

  • Tool accuracy — correct tool + valid JSON args
  • Task success — final state matches expected outcome
  • Steps to success — penalize unnecessary loops
  • Golden set — 20 queries with expected tool sequence
Chapter 4

Retrieval evaluation

  • Recall@k / MRR — gold doc in top-k?
  • Context recall — gold answer inferable from retrieved text
  • Ablation table — dense vs BM25 vs hybrid vs +rerank
Chapter 5

LangGraph / memory evaluation

  • Resume rate — same thread_id continues without re-asking facts
  • Store recall — new thread_id still loads user preferences
  • Interrupt compliance — dangerous tools pause until approved

Workflow

Recommended eval workflow

  1. Define task — one sentence user goal per test case.
  2. Build golden set — 20–50 cases with expected outcome (doc ID, tool, answer snippet).
  3. Component eval first — retrieval before end-to-end RAG; tools before full agent.
  4. Automate — RAGAS, jiwer, custom scripts in CI on every index/model change.
  5. Human spot-check — 10% sample weekly; focus on failures.
  6. Regression gate — block deploy if Recall@5 or task success drops >2%.
