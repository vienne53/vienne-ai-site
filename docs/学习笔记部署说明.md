# 学习笔记 · 课程同步与部署

把 `王瑛楠aipm/course/llm-agent` 里的 **HTML 成品** 同步到本站 `learn/llm-agent/`，推 GitHub 后 Vercel / GitHub Pages 自动上线。

## 目录结构

```
vienne-site/
├── index.html              # 主页「学习笔记」区块 → 课程入口
├── notes.html              # 学习笔记汇总页
└── learn/llm-agent/        # 9 章课程（静态 HTML）
    ├── present-hub.html    # 课程中心（推荐入口）
    ├── course-present*.html
    └── course-full-*.html
```

## 一键同步（Windows）

在 PowerShell 执行（改源路径为你的课程目录）：

```powershell
cd D:\vienne-site
.\scripts\sync-learn-course.ps1
```

或手动：

```powershell
$src = "D:\Desktop\王瑛楠aipm\course\llm-agent"
$dst = "D:\vienne-site\learn\llm-agent"
New-Item -ItemType Directory -Force -Path $dst | Out-Null
Copy-Item "$src\course-*.html" $dst -Force
Copy-Item "$src\present-hub.html" $dst -Force
Copy-Item "$src\cheat-sheet.md" $dst -Force -ErrorAction SilentlyContinue
```

**不要复制** `build_courses.py`、`chapters_content.py` 等构建脚本（仅本地生成用）。

## 部署

### 方式 A：Vercel（推荐，与 AI 分身同域）

1. 提交并推送 `main`：
   ```powershell
   cd D:\vienne-site
   git add learn notes.html index.html docs
   git commit -m "feat: add LLM to Agent course under learn/llm-agent"
   git push origin main
   ```
2. Vercel 自动部署（仓库已绑定时无需额外配置）。
3. 访问：
   - `https://vienne-ai-site.vercel.app/notes.html`（生产域名）
   - `https://vienne-ai-site.vercel.app/learn/llm-agent/present-hub.html`
   - 自检 API：`https://vienne-ai-site.vercel.app/api/health` → 应见 `"configured": true`

> **国内打不开 `*.vercel.app`？** 这是网络/DNS 问题，不是部署失败。海外访问正常。解决办法见下方「国内访问 Vercel」。

### 国内访问 Vercel

症状：`ERR_CONNECTION_TIMED_OUT`，或 DNS 解析到 `31.13.x.x`（错误 IP）。

| 方案 | 说明 |
|------|------|
| **VPN / 代理** | 开发、管理 Vercel 控制台、预览部署时开启 |
| **自定义域名（推荐生产）** | Vercel → Project → Settings → Domains，绑定如 `www.你的域名.com`，DNS 按 Vercel 提示 CNAME 到 `cname.vercel-dns.com`；访客走你的域名，比 `*.vercel.app` 在国内更稳 |
| **改 DNS** | 路由器/网卡 DNS 改为 `8.8.8.8` 或 `223.5.5.5`（仅解决 DNS 污染；若 IP 仍被拦，还需 VPN 或自定义域名） |

不要用 **Preview 链接**（形如 `xxx-vienne53s-projects.vercel.app`）当正式地址；用生产域名 `vienne-ai-site.vercel.app` 或绑定的自定义域名。

### 方式 B：GitHub Pages

若 Pages 源为 `main` 分支根目录，URL 形如：

- `https://vienne53.github.io/vienne-ai-site/notes.html`
- `https://vienne53.github.io/vienne-ai-site/learn/llm-agent/present-hub.html`

课程内链接均为**相对路径**，放在子目录 `learn/llm-agent/` 下无需改链接。
